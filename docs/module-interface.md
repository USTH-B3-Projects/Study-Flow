# StudyFlow Module Interface

This document defines the public function interfaces for the JavaScript service modules. It is a shared contract for implementation and integration. Function names and parameters should not be changed without informing the team.

## General conventions

- Every function listed here must be exported from its service file.
- IDs are generated by the system when a user, course, or task is created.
- A function returning `null` means that the requested object was not found.
- A function returning `boolean` reports whether an operation succeeded.
- `estimatedDuration` defaults to `3` hours when the user leaves it empty.
- Task `status`, remaining workload, score, and warning values are derived by the system.
- Overdue is a derived state based on the deadline; it is not a manually selected task status.

## `storageService.js`

Provides the common interface for reading and writing StudyFlow data in `localStorage`.

| Function | Parameters | Expected return | Responsibility |
| --- | --- | --- | --- |
| `initStorage()` | None | `void` | Initialize missing StudyFlow storage keys with their default values. |
| `getData(key)` | `key: string` | `any` | Read and parse data stored under a key. |
| `saveData(key, data)` | `key: string`, `data: any` | `void` | Convert data to JSON and save it under a key. |
| `removeData(key)` | `key: string` | `void` | Remove data stored under a key. |

### Storage keys

| Key | Initial value | Purpose |
| --- | --- | --- |
| `studyflow_users` | `[]` | Registered user accounts. |
| `studyflow_current_user` | `null` | The currently authenticated user. |
| `studyflow_courses` | `[]` | Course records. |
| `studyflow_tasks` | `[]` | Task records. |

## `authService.js`

Manages registration, authentication, and the current login session.

| Function | Parameters | Expected return | Responsibility |
| --- | --- | --- | --- |
| `register(studentId, email, password)` | Three strings | `User` or operation result | Validate and create a new student account. |
| `login(studentId, password)` | Two strings | `User` or operation result | Authenticate a student and store the current user. |
| `logout()` | None | `void` | End the current session by removing the current user. |
| `getCurrentUser()` | None | `User \| null` | Return the currently authenticated user. |
| `isAuthenticated()` | None | `boolean` | Report whether a user is currently logged in. |

## `courseService.js`

Manages course data belonging to students.

| Function | Parameters | Expected return | Responsibility |
| --- | --- | --- | --- |
| `createCourse(course)` | `course: object` | `Course` | Generate an ID and create a course. |
| `getCoursesByStudent(studentId)` | `studentId: string` | `Course[]` | Return all courses belonging to a student. |
| `getCourseById(courseId)` | `courseId: string` | `Course \| null` | Return one course by ID. |
| `updateCourse(courseId, data)` | `courseId: string`, `data: object` | `Course \| null` | Update the permitted fields of a course. |
| `deleteCourse(courseId)` | `courseId: string` | `boolean` | Delete a course and coordinate removal of its related tasks. |

### Course creation input

The `course` object contains:

- `courseName`
- `color`
- `studentId`

The service generates `courseId` and creation metadata.

## `taskService.js`

Manages task CRUD operations, progress, completion, and task queries.

| Function | Parameters | Expected return | Responsibility |
| --- | --- | --- | --- |
| `createTask(taskData)` | `taskData: object` | `Task` | Generate an ID, apply defaults, and create a task. |
| `getTasksByStudentId(studentId)` | `studentId: string` | `Task[]` | Return all tasks belonging to the student's courses for the Dashboard and global recommendation. |
| `getTasksByCourseId(courseId)` | `courseId: string` | `Task[]` | Return all tasks in one course for Course Detail and local recommendation. |
| `getTaskById(taskId)` | `taskId: string` | `Task \| null` | Return one task by ID. |
| `updateTask(taskId, data)` | `taskId: string`, `data: object` | `Task \| null` | Update the permitted fields of a task. |
| `deleteTask(taskId)` | `taskId: string` | `boolean` | Delete one task. |
| `updateTaskProgress(taskId, currentProgress)` | `taskId: string`, `currentProgress: number` | `Task \| null` | Update progress and synchronize the task status. |
| `markTaskCompleted(taskId)` | `taskId: string` | `Task \| null` | Set progress to 100 and status to completed. |
| `getOverdueTasks(studentId)` | `studentId: string` | `Task[]` | Return the student's incomplete tasks whose deadlines have passed. |

### Task creation input

The `taskData` object contains:

- `courseId`
- `taskName`
- `deadline`
- `importance`
- `estimatedDuration` (optional; defaults to 3 hours)
- `currentProgress`

The service generates `taskId`, timestamps, and derived values.

## `smartService.js`

Calculates smart scores, ranks pending tasks, provides recommendations, and detects workload risk.

| Function | Parameters | Expected return | Responsibility |
| --- | --- | --- | --- |
| `calculateUrgencyScore(deadline)` | `deadline: string \| Date` | `number` | Calculate urgency from the time remaining until the deadline. |
| `calculateImportanceScore(importance)` | `importance: string` | `number` | Convert an importance level to its numeric score. |
| `calculateRemainingWorkload(estimatedDuration, currentProgress)` | Two numbers | `number` | Calculate the estimated hours of work remaining. |
| `calculateWorkloadScore(remainingWorkload)` | `remainingWorkload: number` | `number` | Convert remaining workload into its numeric score. |
| `calculatePriorityScore(task)` | `task: object` | `number` | Calculate the final priority score of one task. |
| `rankTasks(tasks)` | `tasks: Task[]` | `Task[]` | Remove completed tasks and return the remaining tasks in priority order. |
| `getGlobalRecommendations(studentId)` | `studentId: string` | `Task[]` | Return the ranked pending tasks across all of a student's courses. |
| `getLocalRecommendations(courseId)` | `courseId: string` | `Task[]` | Return the ranked pending tasks within one course. |
| `getWorkloadWarning(tasks)` | `tasks: Task[]` | Warning result | Identify risky pending tasks from their urgency and workload scores. |

### Ranking order

When two tasks have the same priority score, use the following tie-breaking order:

1. Priority score: descending.
2. Deadline: ascending.
3. Importance: descending.
4. Created time: ascending.

### Workload warning scope

The web version does not collect available study time. Therefore, `getWorkloadWarning(tasks)` detects workload risk from the combination of urgency and workload score. It must not claim that the user has insufficient available hours.

A completed task does not produce a workload warning. An overdue task should be labeled separately as overdue.

## Module dependencies

| Module | May use |
| --- | --- |
| `authService.js` | `storageService.js` |
| `courseService.js` | `storageService.js` |
| `taskService.js` | `storageService.js`, course data when filtering by student |
| `smartService.js` | `taskService.js` and task data |

Page scripts and UI components may call service functions, but service modules must not directly manipulate HTML elements.
